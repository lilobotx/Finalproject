Quality

This is the quality of the format. It shows how well the format preserves image details and colors. It is based on the average quality of a image from this format and not the maximum quality.

This is the efficiency of the format. It shows how well the format balances quality and file size.

This is the speed of the format. It shows how quickly the format can be loaded and displayed in web based scenarios. This is mostly based on the file size of the format where lower file sizes will score higher.
